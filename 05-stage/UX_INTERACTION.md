## 二、核心交互逻辑（7 条）
### 逻辑 1：导航即信息架构（单页应用 + Tab 切换）
- 全站是 **SPA 单页应用**，7 个板块通过顶部导航 Tab 切换，无需跳转刷新
- ✅ 好处：用户 1 秒内看清"这个大赛有什么"，零学习成本
- ✅ 反向应用：你的参赛作品/路演页也用"导航=信息架构"组织，让评委 30 秒看全
### 逻辑 2：首页只放"成交三要素"
首页不堆信息，只放 3 样东西：
1. **奖金池大字**（370,000 元）→ 制造吸引力
2. **一句话主题**（"引领应用美学黑客松"）→ 明确调性
3. **提交截止按钮**（恒定可见）→ 唯一行动号召 CTA
- ✅ 反向应用：你的 Demo 首页首屏 = 一句价值主张 + 一个核心 CTA
### 逻辑 3：行动号召（CTA）恒定在场
- **提交截止按钮**：左下角恒定显示，任何时候用户想报名都找得到
- **官方交流群**：右侧恒定悬浮，随时可进群
- ✅ 反向应用：作品里每个页面都放一个"主 CTA"，别让用户找半天
### 逻辑 4：获奖作品是"信任状"，放在显眼位置
- 获奖作品板块直接展示**可点击的作品卡片网格**（名称+预览图+简介）
- 点进去就是**真实可运行的 demo**（不是截图）
- ✅ 反向应用：你的作品集/路演页也把"已获奖/已落地"的案例放前面，作为信任背书
### 逻辑 5：奖金用轮播"逐个展示"而非列表堆叠
- 奖金板块用**轮播**逐项展示（冠军→亚军→季军→特色奖）
- 有左右切换 + 指示点，每个奖项单独一屏，信息不拥挤
- ✅ 反向应用：多奖励/多亮点时用轮播或卡片分屏，别一屏塞满
### 逻辑 6：赛事日程用"时间线"建立紧迫感
- 日程板块是**竖向时间线**：启动→报名→评审→公布→颁奖
- 每个节点有日期 + 说明，清晰展示"现在在哪一步、下一步是什么"
- ✅ 反向应用：路演页用时间线展示产品演进/计划，评委一看就懂节奏
### 逻辑 7：规则/信任信息"卡片化"平铺
- 参赛规则、评委履历都用**卡片**展示（白/5% 半透明卡片 + 细边框）
- 评委 = 头像 + 姓名 + 头衔 + 履历，权威感强
- ✅ 反向应用：团队介绍、资质展示用统一卡片，专业感瞬间提升

## 四、官网交互逻辑 → 参赛作品的反向应用
做黑客松参赛作品时，把官网这套交互逻辑反用到你的 Demo 页面：
| 官网做法 | 你的作品怎么做 |
|---|---|
| 奖金大字 + 一句主题 + CTA | 首页首屏 = 价值主张 + 核心按钮 |
| Tab 导航 = 信息架构 | Demo 顶部导航让评委 30 秒看全功能 |
| 获奖作品可点击 demo | 你的作品关键功能都做可交互，别留静态图 |
| 奖金轮播逐个展示 | 多亮点分屏展示，别堆一屏 |
| 日程时间线 | 用时间线展示产品演进/项目计划 |
| 评委/规则卡片化 | 团队/资质用统一卡片 |
| 交流群 + CTA 恒定 | 关键操作按钮恒定可见 |
| SPA 无刷新切换 | Demo 内切换丝滑，别整页刷新 |

## 五、可用性检查清单（参赛页提交前）
- [ ] 30 秒内能否看懂"这是什么 + 我能得到什么"？
- [ ] 首屏有没有明确 CTA（报名/体验/查看）？
- [ ] 关键信息（奖金/时间/规则）是否一眼可见？
- [ ] 是否有可点击的真实 demo（不是截图）？
- [ ] 信息是否分屏/卡片化，不拥挤？
- [ ] 是否有信任背书（评委/获奖/合作方）？
- [ ] 导航是否清晰，无死胡同？
- [ ] 移动端是否流畅？
