# 🎨 制作流程倒推：先做图片资产，还是先做网站框架？
> 本模块回答一个关键问题：秒哒获奖作品「光靠代码写不出来」吗？
> 我们通过**逆向 4 个获奖作品 + 官网的 JS/CSS 源码**，统计每个作品的
> 图片资产数量、来源（AI 生成/搜索/纯代码）、CSS 渐变与动画密度，
> 用数据回答：**他们的制作流程是先做资产还是先做框架**。
---
## 一、数据实证：4 个作品的资产构成
我们对每个作品下载了 JS bundle + CSS，统计了图片引用与视觉实现方式：
| 作品 | 图片资产 | 图片来源 | 视觉实现方式 | 结论 |
|---|---|---|---|---|
| **遗憾星云**（星空疗愈）| **1 张** | 1 张 AI 生成 | CSS 18 渐变 + 20 keyframes + 26 阴影，星空全程序化 | **纯代码路线** |
| **混世魔牛**（国风 ARPG）| **0 张** | 无 | 51 个 Unicode 字符 + ink 墨风格 CSS + SVG | **纯代码路线** |
| **外滩·折叠的回声**（民国叙事）| **15 张** | 9 张 AI 生成 + 6 张百度搜索 | CSS 94 渐变 + 75 keyframes + 40 阴影 + 8 处图片 | **资产+代码混合** |
| **思豫·中原**（中原文化）| **80 张** | 35 张百度搜索 + 45 张 AI 生成（cfc 插件批量出图）| 章节 banner + 场景图铺满 | **重资产路线** |
### 关键发现
1. **不存在"光靠代码写不出来"**——遗憾星云和混世魔牛证明纯代码能做
2. **但"重情感/重文化"的作品倾向重资产**——外滩 15 张、思豫中原 80 张
3. **AI 生成图片（秒哒/即梦）+ 百度搜索实拍**是最常见资产来源
4. **所有作品 = 图片资产 + CSS 视觉 + 交互动效 三层叠加**，只是权重不同

## 二、倒推：他们的制作流程
### 从资产时间戳推断的流程
思豫中原的 AI 生图插件输出路径带日期：
```
cfc-plugin.../image-generation/app-d59nu3vnzmkh/tasks/task-20260720/...
                                                         ~~~~~~~~~
                                                         7月20日批量生成
```
→ **先批量生成图片素材，再做应用**。
外滩的 9 张 AI 图都在 `20260729`（同一天批量生成）：
```
20260729/09ed...jpg  20260729/0d14...jpg  ...（9张同日期）
```
→ **同一天集中产出所有氛围背景图**，然后搭框架。
### 所以真实流程是：
```
第 1 步：定视觉方向（主题/风格/色彩/情绪）
   ↓
第 2 步：批量生成图片资产（AI 生图，一次出一批，选最好）
   ↓
第 3 步：搭应用框架（页面结构/导航/信息架构）
   ↓
第 4 步：把图片资产贴进框架（背景图/卡片图/氛围图）
   ↓
第 5 步：叠加 CSS 视觉（渐变/动画/阴影/字体）让资产"活"起来
   ↓
第 6 步：加交互动效（悬停/点击/滑动/加载反馈）
   ↓
第 7 步：打磨细节（响应式/性能/一致性）
```
**核心：先有"视觉锚点"（图片资产），再搭框架。**
因为：图片资产定了整个作品的调性、配色、情绪，框架围绕它展开。

## 三、三种制作路线的选择标准
| 路线 | 适合场景 | 优点 | 缺点 | 代表作品 |
|---|---|---|---|---|
| **纯代码路线** | 科技感/极简/抽象 | 零资产成本、性能好、可复用 | 情感浓度有限、难做写实 | 遗憾星云、混世魔牛 |
| **资产+代码混合** | 叙事/情感/氛围 | 画面震撼、情绪浓 | 需生图时间、图片加载 | 外滩·折叠的回声 |
| **重资产路线** | 文化/教育/内容型 | 内容信息量大、直观 | 资产成本最高、体量最大 | 思豫·中原 |
### 黑客松建议
**预算低/时间紧** → 纯代码路线（CSS 渐变 + 字体 + 交互动效）
**主题需情感/叙事** → 混合路线（AI 生 3-5 张关键氛围图 + 代码搭框架）
**内容信息型** → 重资产（但注意 80 张图会拖慢演示）

## 四、如何生成图片资产（零成本方案）
### 方式 1：AI 生图（推荐，质量高）
- 秒哒内置 AI 生图、即梦、豆包图片生成
- **一次批量生成 10-20 张**，从里面选 3-5 张最好的
- 提示词要点：风格统一（"民国黑白复古颗粒感"）+ 主题明确（"上海外滩夜景"）
### 方式 2：搜索实拍图（次选，快）
- 外滩用了 `baidu_image_search`（百度图片搜索）
- 适合地标/真实场景（黄鹤楼、龙门石窟、外滩）
- 注意版权：黑客松非商用可接受，商用需换版权图库
### 图片资产清单（按作品类型）
| 作品类型 | 需要的图片 | 数量 |
|---|---|---|
| 情感疗愈 | 主视觉氛围图（星空/海洋）| 1-3 张 |
| 叙事解谜 | 场景背景图（每个章节 1 张）| 5-10 张 |
| 文化教育 | 地标/文物图 + 章节 banner | 10-80 张 |
| 游戏类 | 可纯代码（字符+渐变）| 0 张 |

## 五、完整制作流程模板（黑客松可直接用）
```
■ 阶段 1：创意定调（30 分钟）
  □ 定主题/情绪/风格（参考 UI_AESTHETICS.md 的 5 大配方）
  □ 写出"一句话概念"（如"把遗憾留在宇宙，把星光带回现实"）
  □ 定主色 + 字体（暗黑科技→金橙+等宽；治愈→水彩+圆体）
■ 阶段 2：资产生产（1-2 小时）
  □ 用 AI 生图批量生成主视觉 + 氛围图（10-20 张选 3-5）
  □ 或搜索实拍图（地标/场景）
  □ 导出统一尺寸、压缩（WebP）
■ 阶段 3：框架搭建（2-4 小时）
  □ 定信息架构（参考 UX_INTERACTION.md：导航/首页/内容/CTA）
  □ 搭页面骨架（HTML 结构/CSS 布局）
  □ 定交互骨架（页面流转/表单流程）
■ 阶段 4：视觉合成（2-3 小时）
  □ 把图片资产贴进框架
  □ 叠加 CSS 渐变/动画/阴影（参考 HERO_FLUID_MOTION.md）
  □ 加动效：悬停/点击/加载（参考 UX_INTERACTION_MOTION.md）
■ 阶段 5：打磨交付（1-2 小时）
  □ 响应式检查
  □ 性能优化（图片压缩/动画节流）
  □ 演示流程彩排（确保 3 分钟讲完亮点）
```
---
## 六、一句话总结
> **获奖作品不是"光靠代码写不出来"，而是"图片资产定调 + 代码搭框架"双轮驱动。**
> 情感/文化类作品：先花 1-2 小时批量生成图片资产（视觉锚点），再搭框架；
> 科技/极简类作品：纯 CSS/JS 程序化即可，零资产成本。
> **关键不是选哪条路，而是让"资产"和"代码"服务于同一个视觉主张。**
