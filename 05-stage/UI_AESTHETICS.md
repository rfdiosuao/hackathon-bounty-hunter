# 🎨 黑客松 UI 美学模块（UI Aesthetic Distillation）
> 本模块蒸馏自「外滩黑客松·AI Coding 大赛 + 秒哒应用美学黑客松」的 13 个获奖作品。
> 核心结论：**黑客松获奖 = idea 60% + UI 炸裂 20% + 路演讲故事 20%**。
> UI 是作品的"第一印象分"，评委 30 秒扫过就决定是否深入看你的作品。
---
## 一、为什么 UI 在黑客松如此重要
| 维度 | 占比 | 说明 |
|---|---|---|
| **Idea** | 60% | 解决什么问题、为什么是你 |
| **UI 呈现** | 20% | 第一印象、审美判断、完成度信号 |
| **路演叙事** | 20% | 3 分钟讲清价值、引发共鸣 |
**评委的心理机制**：
1. 30 秒扫视作品 → 形成"是否专业/是否用心"的判断
2. 视觉质感 = 完成度信号（粗糙 UI 会被认为想法也没打磨）
3. 审美即品味 → 评委默认：UI 好的团队，产品 Sense 也强
4. 可分享性 → 评委需要向其他评委/主办方推荐，好看的作品才"拿得出手"

## 三、获奖 UI 的 7 大设计逻辑（核心）
### 逻辑 1：一个强烈的主视觉锚点（30 秒法则）
- 每个获奖作品都有一个**一眼难忘的主视觉**：遗憾星云的紫蓝星球、混世魔牛的暗黑山门、外滩的车窗、绮罗间的国风底图
- ❌ 避免：通用渐变背景 + 普通卡片（无记忆点）
- ✅ 做法：先定"这个作品长什么样让人 30 秒记住"，再填充功能
### 逻辑 2：主题一致性 > 功能堆砌
- 所有获奖作品**视觉完全围绕一个主题**：民国风就全是民国元素、星空就全是星云元素
- 字体、配色、动效、文案口吻全部统一
- ❌ 避免：首页酷炫，内页变普通后台
- ✅ 做法：定一份"主题设计系统"（色板+字体+动效+语气），全站统一
### 逻辑 3：情绪价值 >> 功能价值
- 遗憾星云不是"记录遗憾的工具"，而是"**把遗憾封存成星球**"的仪式
- 人生包装不是"情绪管理APP"，而是"**把现在的自己包装成人生产品**"
- ✅ 做法：给功能一个**情感化的叙事包装**，让用户"被打动"而不是"被使用"
### 逻辑 4：参与感设计（让用户留下点东西）
- 申光纪"点亮自己的上海记忆"、外滩"生成专属时空身份卡"、遗憾星云"创建自己的星球"
- ✅ 做法：设计一个**用户产出的闭环**（生成卡片/创建星球/点亮记忆），可分享 = 传播
### 逻辑 5：中英双语/多语言 = 国际质感
- 书境 `LIBRARY OF BOOK VIBES`、疗愈网站 `LE HAVRE DE PAIX`、外滩 `THE UNSEEN BUND`
- 中英双语排布让界面看起来更"设计过"，评委的视觉品味信号
- ✅ 做法：标题配英文副标、装饰性英文排版
### 逻辑 6：细节动效是完成度的放大器
- 混世魔牛的刀光粒子、思豫的麦芒浮动、失物招领的抽卡
- ✅ 做法：关键交互加一个**恰到好处的动效**（入场/悬停/切换），不做满屏乱动
### 逻辑 7：第一屏就说清"这是什么"
- 所有作品首屏都有**一句话点题**（slogan + 副标题）
  - 遗憾星云："把遗憾留在宇宙，把星光带回现实"
  - 绮罗间："观天地之色，识衣冠之纹"
  - 书境："每一本书，都是一种氛围"
- ✅ 做法：首页首屏必须有一句**能当广告语的 slogan**

## 四、可复用的设计配方（直接套用）
### 配方 A：暗黑科技 + 情感叙事（适合 AI 情感/数据产品）
- 背景：`#0a0a12` 深空黑，星星点点的噪点
- 主色：紫蓝星球渐变 `#7c6cff → #3a2f8a`
- 字体：细体无衬线 + 大留白排版
- slogan 句式："把 X 留在 X，把 X 带回 X"
### 配方 B：国风水墨 + 数字图鉴（适合文化/IP 类）
- 背景：米白宣纸色 `#f5f0e6` + 水墨元素
- 主色：胭脂红 `#b03a2e` + 石青 `#3d7a6b` + 朱砂 `#c0392b`
- 字体：衬线/楷体标题 + 竖排装饰文字
- 元素：印章 logo、传统色卡、纹样底纹
### 配方 C：复古怀旧 + 档案馆（适合时代记忆类）
- 背景：深色 `#1a1512` + 老照片磨砂
- 主色：暖黄 `#c9a227` + 复古棕
- 字体：衬线 + 老式海报排版
- 玩法：收集/陈列/抽卡/时光机
### 配方 D：清新治愈 + 拟物（适合情绪/生活类）
- 背景：浅米色 `#faf6f0` + 柔和阴影
- 主色：奶油白 + 低饱和莫兰迪
- 字体：圆润无衬线 + 手写体点缀
- 玩法：拟物包装/配料/随机拆开
### 配方 E：极简黑白 + 专业工具（适合工具/平台类）
- 背景：纯白/纯黑 + 红点缀 `#e63b2e`
- 字体：粗体无衬线标题 + 等宽数字
- 元素：版本号（VOL.2026.08）、功能菜单、专业 icon

## 五、UI 落地检查清单（提交前自检）
- [ ] 首屏 30 秒能否记住主视觉？
- [ ] 有没有一句能当广告语的 slogan？
- [ ] 全站主题是否一致（色板/字体/动效/口吻）？
- [ ] 是否有用户产出闭环（生成/收藏/点亮/分享）？
- [ ] 是否有恰到好处的关键动效？
- [ ] 是否有中英双语提升质感？
- [ ] 移动端是否可用？（评委可能用手机看）
- [ ] 是否有"可分享出去"的传播点？

## 六、模块使用流程
```
1. 定 Idea（03-pathfinder）
2. 定主视觉锚点 → 从上面 5 个配方选一个基调
3. 用配方生成首页首屏（slogan + 主视觉）
4. 全站统一主题设计系统
5. 加参与感闭环 + 关键动效
6. 对照检查清单自检
7. 截图/录屏用于路演（05-stage）
```
