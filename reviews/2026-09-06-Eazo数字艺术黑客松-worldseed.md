## 三、聚类观察与根因

1. **上线无声事故**：9/5 改完语音代码后未 rebuild，服务器 dist（18:55 旧包）不含语音代码，前端静默降级到系统 TTS。根因：改源码后缺"构建-验证-部署"检查单；Vite 未清理 outDir 还残留旧 hash 文件。
2. **豆包 TTS 集成两次返工**：上游 HuggingFace 存储失败时返回相对路径 `/audio/...`，Worker 直接 fetch 相对 URL 抛异常（1101）；且该路径需 Basic Auth。根因：集成时只按"正常路径"写，没覆盖上游降级路径。
3. **中文编码假象**：PowerShell 下 curl 测中文请求出现乱码，一度误判"LLM 答非所问"。根因：测试环境编码问题被当成了产品 bug（教训：副作用排查先换干净环境复现）。
4. **本地代理干扰出网**：127.0.0.1:7897 代理导致 workers.dev SSL/超时异常，排查耗时。根因：多环境网络配置未提前约定。

## 四、做对了什么（保留项）

1. **SKILL 人格蒸馏**：用 SKILL(1).md 把白小纯人格压缩进 system prompt（身份→三层性格→反差切换→反应链→动作=内心影子），输出强制 JSON schema，后端对 heart/mood/action 枚举归一化 + worldCommand 兜底触发，保住"一念成界"核心功能不跑偏。
2. **三层兜底永不黑屏**：Marble 实时生成 → 赛前预生成世界库 → 离线 2.5D。
3. **密钥零暴露**：所有 API key 存 Cloudflare Worker secrets，前端只拿端点 URL；豆包 Basic Auth 密码只存 secret 不进仓库。
4. **/tts 契约稳定**：换 TTS 供应商（火山 → 豆包）前端零改动，接口契约先于实现。
5. **素材快速收敛**：白底抠图返工一次后，改用用户预抠好的素材直接替换，不再死磕算法。
6. **利他路演法**：用 prize-ops 06-sprint 的利他三层结构改稿，把评委"艺术爆炸"观点化用进收尾（身份钩子），"烧 7000 额度"当真实性素材，2 分钟定稿。
