Hackathon Bounty Hunter

黑客松赏金猎人 · 七阶段工作流

从「发现比赛」到「拿奖复盘」的端到端闭环 · 每个人按此流程执行即可系统性提升获奖概率

全自动（定时任务） 人机协作 阶段产出 反馈循环
0
情报雷达 全自动 · 每天 9:00 / 20:00
触发：定时任务 cron 自动触发
动作：多源抓取（HackHQ + 观猹 watcha + 小红书博主 + Lablab.ai + 大厂赛事 + 公众号）→ 按位置/预算/截止筛选 → 去重 → 多通道推送
关联模块：01-radar/ 全部脚本
📦 产出：比赛清单卡片（名称 / 截止 / 奖金 / 报名链接 / 地点）→ 飞书+邮箱+短信
↓
1
报名决策 人机协作
触发：收到推送后，手动选择感兴趣的比赛
动作：用 competition-award-pathfinder 分析规则 → 提取硬门槛（资格/提交数/平台）→ 重建评审漏斗（机筛→专家→决赛→人气）→ 对比 ≥3 条赛道
关联模块：competition-award-pathfinder Step 1-7
📦 产出：参赛决策报告（推荐赛道 + 弃赛理由 + 倒推时间线）
↓
2
创意生成 人机协作 · 核心 60%
触发：确定参赛赛道后
动作：用「反惯性·多视角·闭环验证」提示词 → 悬置第一反应解法 → ≥3 独立视角审视（时间/立场/层次）→ 把握度分级+闭环学习 → 倒推评分维度生成 idea
关联模块：Step 7.5 创意生成
📦 产出：3-5 个差异化 idea + 推荐路线 + 核心 demo 定义
↓
3
UI/UX 设计 人机协作 · UI 一定要炸
触发：idea 确定后
动作：选风格（民国复古/暗黑国风/水彩治愈/星空数据…）→ 设计交互逻辑 → 鼠标交互动作 → 首屏流体动效 → 倒推制作顺序（先图片资产 or 先框架）
关联模块：05-stage/ 5 个蒸馏文档 + archive-miaoda 获奖作品
📦 产出：UI 设计规范 + 交互原型 + 图片资产清单
↓
4
开发实现 人机协作
触发：设计规范确定后
动作：按制作流程倒推顺序执行 → 图片资产先行（AI 生成/设计）→ 搭框架填充 → 先做核心 demo（3 分钟可演示的最小闭环）
关联模块：PRODUCTION_FLOW.md 制作流程方法论
📦 产出：可运行 demo + 提交材料（代码/文档/视频）
↓
5
路演准备 人机协作 · 会讲故事
触发：demo 完成后
动作：讲故事框架（痛点→方案→演示→愿景→团队）→ 路演 PPT/文档 → 3min/5min/10min 多版本 → 答辩 Q&A 预案
关联模块：competition-award-pathfinder Step 8-9
📦 产出：路演稿 + PPT + 答辩预案
↓
6
参赛 & 复盘 闭环 · 沉淀经验
触发：比赛当天
动作：提交作品 + 现场路演 → 赛后复盘（哪些有效/哪些失效）→ 沉淀到获奖作品档案 → 优化情报源和创意方法论
关联模块：archive-miaoda/ 获奖作品档案模式
📦 产出：复盘文档 + 可复用经验 + 下一轮迭代输入
🔄 反馈循环（让系统越跑越强）
阶段 6 复盘 → 优化阶段 0 情报源（新增/淘汰信息源、调整筛选阈值）
阶段 6 复盘 → 迭代阶段 2 创意方法论（验证哪些 idea 模式真的能拿奖，沉淀为可复用模板）
阶段 6 获奖作品 → 补充阶段 3 UI 档案（新增获奖作品拆解，扩充风格库）
