Hackathon Bounty Hunter v2.0

黑客松赏金猎人 · 七阶段工作流

从「发现比赛」到「拿奖复盘提PR」的端到端闭环 · 含自动参赛轻量通道 · 每个人按此流程执行即可系统性提升获奖概率

🏆 黑客松获奖公式
Idea 60% + UI 20% + 路演 20%
最小可演示闭环 · 做少做精做炸 · 不追求项目完成度
全自动（定时任务） 人机协作 阶段产出 反馈循环
1
情报雷达 全自动 · 每天 9:00 / 20:00
触发：定时任务 cron 自动触发
动作：多源抓取（HackHQ + 观猹 watcha + 小红书3博主 + Lablab.ai + 大厂赛事 + 公众号搜索）→ 按位置/预算/截止筛选 → 去重 → 多通道推送（飞书为主 + 邮箱/短信为辅）
关联模块：01-radar/ fetch_hackathons.py + send_feishu.py
📦 产出：比赛清单卡片（名称 / 截止 / 奖金 / 报名链接 / 地点）→ 飞书推送
↓
2
筛选罗盘 人机协作 · 双通道分流
触发：收到推送后，选择感兴趣的比赛
动作：用 competition-award-pathfinder 分析规则 → 提取硬门槛 → 重建评审漏斗 → 对比 ≥3 条赛道 → 判断比赛类型
关联模块：02-compass/ + competition-award-pathfinder
⚡ 轻量通道（线上提交制）
自动参赛 Agent：扫描GitHub → AI匹配项目 → 自动包装 → 半自动提交 → 结果自动跟踪（每5天） → 获奖触发复盘

3
深度分析 + 创意生成 人机协作 · 核心 60%
触发：确定走重量通道后
动作：深度拆解比赛规则 → 用「反惯性·多视角·闭环验证」提示词生成 idea → 悬置第一反应 → ≥3 独立视角审视 → 把握度分级 → 倒推评分维度生成 3-5 个差异化 idea
关联模块：03-pathfinder/ + Step 7.5 创意生成
📦 产出：3-5 个差异化 idea + 推荐路线 + 核心 demo 定义
↓
4
作品武器库 人机协作 · UI 一定要炸
触发：idea 确定后
动作：从获奖作品档案选风格 → UI设计规范 → 交互逻辑 → 鼠标交互动作 → 首屏流体动效 → 倒推制作顺序（先图片资产 or 先框架）→ 按最小MVP标准砍功能
关联模块：04-arsenal/ + 05-stage/ 5个蒸馏文档 + archive-miaoda 13个获奖作品
📦 产出：UI设计规范 + 交互原型 + 图片资产清单 + 最小MVP功能清单
↓
5
执行冲刺 人机协作 · 最小可演示闭环
触发：设计规范确定后
动作：按制作流程执行 → 图片资产先行 → 搭框架填充 → 只做最小可演示闭环（P0功能40%时间 + P1 UI 25%时间） → 设计哇时刻 → 不追求项目完成度
关联模块：06-sprint/ minimum-demo-loop.md + PRODUCTION_FLOW.md
📦 产出：可运行 demo（3分钟可演示的最小闭环）+ 演示视频（45-90秒）
↓
6
路演舞台 人机协作 · 会讲故事 · 丝滑动画
触发：demo 完成后
动作：写逐字稿 → Gamma生成PPT初稿 → PowerPoint精修动画（统一Fade + 缓入缓出 + Morph转场 + 嵌入演示视频）→ 10页5分钟模板 → 排练配合语速 → 答辩Q&A预案
关联模块：06-sprint/PITCH_DECK.md 丝滑动画PPT指南
📦 产出：路演稿 + 丝滑动画PPT（含嵌入视频）+ 答辩预案
↓
7
复盘结晶 全自动闭环 · 自动提PR
触发：比赛结束（获奖 or 未获奖）
动作：交互式复盘问卷（七维度自评 + 失败原因 + 评委反馈 + 改进Top3）→ 规则引擎分析短板（idea/UI/故事哪个不行）→ 生成复盘文档（含雷达图）→ 自动创建分支+提交+创建PR到总仓库
关联模块：07-crystal/ review_hackathon.py（502行）
📦 产出：复盘文档 + 针对性优化建议 + 自动PR（越多人用，项目越强）
⚡ 轻量通道补充：结果自动跟踪
自动参赛提交后 → 云电脑保存登录态 → 每5天自动访问记录页 → 状态机跟踪（已提交→初审→入围→复赛→决赛→获奖/未获奖）→ 状态变化立即推送 → 获奖触发领奖指南+复盘 → 未获奖触发复盘+推荐下一场
🔄 反馈循环（让系统越跑越强 · 越多人用越强）
阶段7复盘PR → 优化阶段1情报源（新增/淘汰信息源、调整筛选阈值）
阶段7复盘PR → 迭代阶段3创意方法论（验证哪些idea模式真的能拿奖）
阶段7获奖作品 → 补充阶段4 UI档案（新增获奖作品拆解，扩充风格库）
阶段7复盘PR → 优化阶段6路演模板（沉淀有效的叙事结构和动画模式）
