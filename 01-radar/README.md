# 🚀 黑客松雷达 - 使用说明

## 系统概述

自动扫描全网黑客松/竞赛信息，发现新增比赛后推送到你的邮箱，报名后自动分析获奖路径并生成 idea + 路演稿。

## 文件结构

```
hackathon-radar/
├── fetch_hackathons.py    # 抓取脚本（HackHQ 结构化数据）
├── generate_email.py      # 邮件内容生成（HTML + 纯文本）
├── send_email.py          # SMTP 邮件发送
├── config.json            # 配置文件（邮箱、SMTP）
├── pushed.json            # 已推送记录（自动维护）
├── latest_all.json        # 本次抓取全量数据
├── latest_new.json        # 本次新增数据
├── email_content.html     # 生成的邮件 HTML
└── email_content.txt      # 生成的邮件纯文本
```

## 配置 QQ 邮箱授权码（必做）

当前邮件发送需要 QQ 邮箱授权码，配置步骤：

1. 登录 [QQ 邮箱](https://mail.qq.com)
2. 进入「设置」→「账户」
3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
4. 开启「SMTP服务」，点击「生成授权码」
5. 把16位授权码告诉我，我会写入 config.json

配置后测试：
```bash
cd hackathon-radar
python3 fetch_hackathons.py
python3 generate_email.py
python3 send_email.py
```

## 定时任务

- **执行时间**：每天 09:00 和 20:00（北京时间）
- **执行内容**：
  1. 运行抓取脚本获取结构化数据
  2. 搜索中文黑客松信息补充来源
  3. 合并去重，对比已推送记录
  4. 有新增则发送邮件（或飞书消息）
  5. 更新已推送记录
- **管理命令**：告诉我"查看黑客松雷达任务"、"暂停雷达"、"修改扫描时间"即可

## 报名后如何使用分析功能

报名比赛后，把以下任一信息发给我：
- 比赛规则文档（PDF/飞书文档/链接）
- 比赛官网链接
- 复制粘贴的规则文本

我会用 **competition-award-pathfinder** 方法论执行：

1. **证据账本**：提取所有赛道、奖项、评审标准，标注来源和证据等级
2. **硬门槛检查**：身份、平台、提交格式、公网部署等资格限制
3. **评审漏斗重建**：机器检测→AI初筛→专家复核→人气投票，每阶段的失败模式
4. **路线比较**：至少3条不同参赛路线的 Pareto 比较
5. **作品反向设计**：从评分机制倒推作品方向、核心演示、记忆点
6. **倒排执行计划**：按截止日期倒推的开发日历

输出：3个针对性 idea + 路演文档框架 + 获奖概率最高的推荐路线。

## 常见问题

**Q: 为什么第一次没有收到邮件？**
A: 需要先配置 QQ 邮箱授权码。未配置时会降级为飞书消息推送。

**Q: 会重复推送同一个比赛吗？**
A: 不会。pushed.json 记录了所有已推送比赛的 ID，新增才推送。

**Q: 能增加短信推送吗？**
A: 可以，但需要第三方短信服务（阿里云/腾讯云）的 API 密钥。目前环境没有直接发短信的能力。

**Q: 比赛信息准确吗？**
A: 数据来自公开平台，仅供参考。报名前请以官方信息为准，截止日期可能变动。

**Q: 能自动帮我报名吗？**
A: 不建议自动报名（涉及个人信息和账号安全）。系统会推送报名链接，你点击后手动报名。
